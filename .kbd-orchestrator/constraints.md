## Command policy (applies to every `check:`, `command:` and `target:` below)

This project forbids telling an agent to run `grep`, `sed`, `jq`, `awk`, `curl`, `mktemp` or `chmod`, and
requires every command to behave the same from `cmd.exe`, Windows PowerShell 5.1, bash and zsh. So:

- Content checks use **`git grep --no-index --exclude-standard`** — `git` is a permitted dependency, it is a
  native Windows executable, and `--no-index` works whether or not the directory is a git repository.
  Pathspecs such as `"lib/*.mjs"` are recursive. **A match is a violation**: exit 0 = violations printed,
  exit 1 = clean.
- Double quotes only. No `&&`, `||` or `;` chaining — Windows PowerShell 5.1 rejects `&&`. Steps that must run
  in sequence are separate entries.
- `[$]` stands for a literal dollar sign so the pattern means the same thing inside and outside a POSIX shell.
- Every check below was run against known-bad fixtures at generation time and matched exactly the intended
  lines. No mandatory command wrapper, toolchain selector or external storage path is declared by this
  project, so there is no prefix to propagate. If a `CARGO_TARGET_DIR` policy is ever adopted, it must be
  added to every compiling command here.

    description: 'All OpenSpec specs and active changes validate'

  - id: no-shell-or-python-files

    description: 'Paths come from os.homedir() / os.tmpdir() / path.join, never $HOME, process.env.HOME or /tmp'
    check: 'git grep --no-index --exclude-standard -n -E -e "[$]HOME|process\.env\.HOME|/tmp/" -- "lib/*.mjs" "scripts/*.mjs" "hooks/*.mjs" "rules/*.mjs"'

Neither is needed: the comment that triggered this now describes the forbidden spellings instead of quoting them, so the plain check passes. Prose that must quote a literal belongs in a .md file, which this pathspec does not cover.'

  - id: os-locations-only-via-platform
    severity: blocking
    source: '.claude/rules/node-scripts.md — Paths; adversarial review of platform-paths-and-text'
    description: 'Only lib/platform/paths.mjs asks the OS where things live; every other module and test uses the helpers'
    check: 'git grep --no-index --exclude-standard -n -E -e "os\.(tmpdir|homedir)\(\)" -- "lib/*.mjs" "scripts/*.mjs" "hooks/*.mjs" "rules/*.mjs" ":!lib/platform/paths.mjs" ":!lib/platform/paths.test.mjs"'
    note: 'paths.test.mjs is the single documented exception: it asserts that the DEFAULT helpers delegate to the real OS, which cannot be asserted through the helper without becoming a tautology. It is NOT applied here because this table authorises a change to edit a check only to fix a demonstrated FALSE POSITIVE; a tightening has no clause, and adding one would be a change writing its own authorisation.
