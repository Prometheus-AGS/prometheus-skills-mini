# Prometheus Skills Mini 1.15.0

Minor release of the portable mini skill pack, including 104 skills and generated Claude/Codex plugin packages. Package, marketplace and plugin versions are aligned at 1.15.0.

## Changes since v1.13.2

- OpenSpec 1.16.0 is the primary spec engine; Node.js 22.12.0 or later is required (#73).
- KBD policy conflicts require a current, hash-matched acknowledgement; selected-method guidance is consistent across stage skills, and readiness uses canonical task ownership (#80).
- Phase-exit checks reject skipped handoffs without reasons, missing declared outputs and unmetered no-progress budgets (#72).
- Evidence-admission conformance cases 18–23 were verified across source, generated Claude/Codex payloads and a registered isolated Claude Code installation on macOS (#82, closes #81).
- Windows distribution generation terminates correctly, native hook stdin payloads reach dispatch, and worktree identity tests handle canonical Git paths (#83).
- Zod is locked to 4.6.7, resolving GHSA-mrhx-c7xc-m3w5; npm audit reports zero vulnerabilities at release preparation (#84).
- Updated KBD team-enrollment and no-silent-fork guidance, Impeccable guidance, and CI fixes are included (#74–#79).

## Verification and limits

The release PR must pass the existing Windows, macOS and Linux Node 22/24 matrix and real-runtime integration before publication. Exact run links are recorded in the release PR. Generated packages are checked against source.

Installed admission-parity evidence is historical evidence for the tested macOS Claude surface, not a new installation test of this release. Windows/Linux installed-harness parity and the broader #62/#69 scope remain unverified. CI success does not certify every installed harness or optional service. Preserve the full-pack/mini installation-scope restrictions described in README.md.

This is a source release with committed generated plugin packages. GitHub provides source archives; no native binaries or new installers are published. Dependency and service pins in versions.toml and minimumActiveVersion 0.2.0 are unchanged.
