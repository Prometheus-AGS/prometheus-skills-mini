# prometheus-skills-mini 1.17.0

Parity with the full pack's certification work, and OpenSpec 2.1.0.

## What changed

- A `skill-certification` skill, in Node, certifies a skill against five evidence levels.
- `npm run validate:strict` checks every skill against the Agent Skills specification and
  this pack's rules. 93 skills had their frontmatter corrected.
- A session-start hook states the VLBV boundary rule in KBD-managed projects. Set
  `PROMETHEUS_VLBV_DEFAULT` to `always` or `off` to change where it applies.
- Installed skills no longer include `evals/` or a plugin manifest of their own.
- OpenSpec is pinned at 2.1.0 and needs Node.js 22.20.0 or newer. Refreshing OpenSpec
  skills needs Git and access to GitHub; without them the refresh is skipped and reported,
  and work continues.

## Upgrading

1. Use Node.js 22.20.0 or newer.
2. Run `npm ci`.
3. Run `node scripts/doctor.mjs` and apply `copy-skills` if it is offered.

## Not verified

- No part of this release was run on Windows.
- Certification levels C2 (trigger) and C3 (outcome) were not run.
- The six ported eval cases have not been run.
