# Design
## Context
Approved operator plan, 2026-09-29. Child correction escaped cadence; reporting conflated unknown waits with zero; parent publication due remains unresolved.
## Decisions
Canonical KBD owns phases, stages and approvals. Cadence v2 adds child attachments, nested stack and read-only canonical reconciliation through a configured Node adapter. Enter/return never moves a waypoint. Clock continues; no child delivery counters. Unknown metadata or approval is unresolved. Completion requires returned parent, canonical completed child and file evidence for return criteria. Standalone/goal uses explicit ownership and return evidence with no implied KBD authority.
New v2 iterations require feature-specific operation alongside build and launch. Profiles remain120min/every2, prior receipts immutable. Corrective iteration admission is permitted while publication due only with failed operation evidence; due never clears without latest matching publication.
State v2 migration backs up committed history and appends migration event; read-only status remains possible on v1. Full pack shared source copied with digest to mini; adapters outside payload. Activity/report supports unknowns, unique canonical completion events and timing coverage. Optimization honors sample count and stable contracts; one setting within existing bounds.
## Sequence
Implement complete production wiring first. Only then operate real CLI across disposable filesystem/process boundaries. Native Windows unavailable is pending, not claimed. No unit/per-edit checks or hosted validation. Local source policies override obsolete generated test-first context.
## Compatibility and risks
Existing dirty repository files are preserved. Cross-repository edits explicitly approved. Existing external publications and historical child receipts can only be linked by their actual provenance, never converted into invented successful iterations. Changed source requires new build receipts. Optional Karpathy degrades without dropping local learning report. Full pack Node recorder availability is explicit.
