## Why
The installed Boss forces UAR to embedded SurrealDB and obscures service-operation feedback. Operators need usable administration of existing or bundled services, Compass projects, and gateway models without conflicting with the full Prometheus pack.

Revision2 adds the operator's complete UAR administration requirement. Catalog editing alone is insufficient while Boss synthesizes inline artifacts that bypass registered definitions. UAR issue #296 also requires verified run identity to reach remote MCP servers. This revision is for operator review; production execution remains on hold.

## What Changes
- Dedicated UAR, Compass, liter-llm and Services settings with typed preferences, IPC, complete translations and upstream-compatible feature boundaries.
- Discover and explicitly select existing SurrealDB and liter-llm installations; retain embedded UAR and separate service lifecycle ownership.
- Stream action-local progress with durable full logs, cancellation and actionable outcomes.
- Persist Compass project enablement and expose indexing and semantic drift checks.
- Sync the liter-llm fork with upstream, package its provider/model catalogs, administer provider connections/model mappings and configure critic/judge/backup roles.
- Deliver through integration boundaries and native customer-priority release builds; require installed Windows x64 and Apple Silicon acceptance.
- Make UAR's catalog authoritative for selected agent execution, preserve definition revisions across resume, and migrate existing Boss agents without overwriting catalog edits.
- Resolve https://github.com/Prometheus-AGS/universal-agent-runtime/issues/296 with static remote header support and trusted run-scoped remote credentials, isolation, expiry/renewal and reconnect behavior.
- Expand UAR into its own admin workspace covering all available REST families: runtime settings, providers/models, agents/compiler/skills, A2UI/presentations, runs/AG-UI, knowledge, tools, security and protocols. Implement missing supporting APIs and show genuine capability limits.
- Support Boss-linked, gateway-linked and independent UAR model configuration, protected credential references and accurate saved/effective application states.
