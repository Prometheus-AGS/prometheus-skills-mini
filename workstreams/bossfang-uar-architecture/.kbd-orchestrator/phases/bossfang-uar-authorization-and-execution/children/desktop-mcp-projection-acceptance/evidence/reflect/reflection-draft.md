## Lessons Learned

- Keep canonical task completion, artifact QA, individual runtime cases, aggregate command success and installed release certification separate in every handoff.
- Use source/artifact hashes to consume another tool's repair, and distinguish historical emission from later applicability before attributing tests to a merged revision.
- Trace the full critical section and actual persistence callback before accepting an adversarial claim; retain both the finding and its contradiction evidence.
- A consumed native claim is permission to execute, not proof an effect happened. Lost acknowledgment or interrupted execution needs explicit unknown state and reconciliation, without automatic replay.
- State whether cancellation ran a guard or dropped the future, and name the actual tool body measured by a counter.
- Record whole-tree coverage when a constraint says whole tree; a clean source-only scan cannot answer it.
- Avoid global process-title diagnostics when credentials may be in command lines. Keep incident records value-free and do not claim rotation without operator confirmation.

These lessons stay in project-local artifacts. No global/user scope promotion or successful memory writeback is claimed.
